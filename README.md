# 🛒 বাজার দর | BazarDor

A Bangla web application that helps users explore daily prices of essential products in Bangladesh, compare price changes, and browse market information.

## 🛠️ Technologies Used

* Next.js
* React & TypeScript
* Tailwind CSS & DaisyUI
* Better Auth
* MongoDB
* React Hot Toast

## ✨ Key Features

1. **Daily Price Trends** — Explore products with rising and falling prices.
2. **Product Categories** — Browse products by category and sort by price.
3. **Product Details** — View product prices and market-wise information.
4. **User Authentication** — Register and sign in using email, Google, or GitHub.
5. **Profile Management** — View profile information and update your name.
